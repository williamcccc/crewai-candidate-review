# 職缺：AI 應用後端工程師（虛構範例）

## 工作內容
- 設計與開發 LLM 應用的後端服務（RAG、Agent 工作流）
- 建置與維運向量檢索系統，持續優化檢索品質
- 與產品、資料團隊合作，將原型轉為可上線的服務
- 建立評測流程，量化模型與 Prompt 變更的效果

## 必要條件
- 3 年以上 Python 後端開發經驗
- 熟悉 FastAPI 或同等框架，具 RESTful API 設計經驗
- 具備 Redis、PostgreSQL 等資料庫實務經驗
- 熟悉 Docker 與 CI/CD

## 加分條件
- 有 LLM 應用開發經驗（LangChain、LangGraph、CrewAI 等）
- 有向量資料庫（Redis Vector、pgvector、Qdrant 等）實務經驗
- 有帶領小組或指導新人經驗

## 團隊現況
團隊 5 人，目前 RAG 原型已完成，最大的痛點是缺乏把原型穩定上線與建立評測流程的經驗。
